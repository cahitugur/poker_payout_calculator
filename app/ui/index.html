Install the PWA

After you open the new site in your browser, use your browser’s install option so it behaves like a standalone app.

Google Chrome (desktop)

  1. Open the new app in Chrome.
  2. Look for the install icon in the address bar (monitor with down-arrow) or open the three-dot menu (⋮) → Install ChipHappens… / Install page as app… (wording varies by version).
  3. Confirm the install. The app opens in its own window and appears in your app launcher.

Google Chrome (Android)

  1. Open the site in Chrome.
  2. Tap the three-dot menu → Add to Home screen or Install app if Chrome shows an install banner.
  3. Confirm. A home-screen shortcut opens the app in standalone mode.

Safari (iPhone / iPad)

  1. Open the new app in Safari.
  2. Tap the Share button (square with arrow).
  3. Scroll and tap Add to Home Screen, then tap Add.
  4. Launch the app from your home screen for a full-screen, app-like experience.

On Mac, Safari supports adding some web apps to the Dock from the File or Share menu depending on your macOS version; iOS is the most common place players install this PWA.
